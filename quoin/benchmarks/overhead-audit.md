# Overhead audit: quoin `/run` vs plain Claude Code

What a quoin benchmark session pays on top of a plain session on the same
task, where that cost comes from, and what was cut to reduce it.

Regenerate the numbers for any paired run directory with:

```bash
python3 quoin/benchmarks/scripts/overhead_audit.py <run-dir>/<run-id> [--format json]
```

The script is read-only over the run. It pairs every task both arms ran and
reads each row's `transcript.jsonl`, `metrics.json` and `judge.json`. Static
sizes come from this checkout's `quoin/` tree (`--quoin-root` to point
elsewhere) at four characters per token.

## How the cost arises

- **First-call context.** The first model call carries the system prompt, the
  tool and skill listings, CLAUDE.md and the expanded `/run` skill. The quoin
  arm's first call is larger than plain's by a fixed amount, the first-call
  delta.
- **Re-reads.** Every later main-thread turn re-reads that prefix from cache,
  so the delta is paid once per turn. A session with more turns pays it more
  often.
- **Turns.** Setup, framing, the review subagent and commit bookkeeping each
  add model turns that a plain session does not take.

## Findings

Analysis of the numbers above (by hand, not script output):

- **CLAUDE.md is not the problem in the benchmark arm.** The installer deploys
  the slim variant (2.3 KB), not the 39 KB source `CLAUDE.md`; the full rules
  live in `memory/workflow-catalog.md` and are read only on demand. It explains
  4% of the first-call delta.
- **The run skill is the largest always-loaded source.** `SKILL.md` explains
  about half the first-call delta, and every quoin turn re-reads it.
- **Turns cost more than bytes.** quoin takes 1.5× the main-thread turns plus
  6.4 subagent turns. Setup, framing, the review subagent (ran on 18 of 40
  tasks) and commit bookkeeping are where those turns come from.
- **Hooks add no tokens.** The only hook seen in pro-r1 is
  `SessionStart:startup`, and its output was empty in every session.
- **Skill listing** adds about 1.3k tokens. Hiding slash-only skills from the
  model (`disable-model-invocation`) would also block skill-to-skill hand-offs
  such as `/run` → `/run_hard`, so it is left as a candidate, not a cut.
- **Unattributed delta.** About 38% of the first-call delta is not a file
  quoin ships: the benchmark's longer `/run` prompt prefix, the
  skill-invocation wrapper and the formatting of the 31 extra skill and
  slash-command entries.
